# END2ENDWORLD

END2ENDWORLDは、様々なWebコンテンツとデジタル体験を提供するポートフォリオサイトです。

## 📋 サイト構成

### メインページ
- **index.html** - ランディングページ（改修済み）
- **welcome.html** - ウェルカムページ（モダンなアニメーション付き）

### コンテンツページ
- **j/portfolio.html** - Junichi Abeのポートフォリオ
- **wordpress/omikuji.html** - デジタルおみくじアプリ
- **wordpress/typing.html** - 文学タイピングゲーム

- **HTML5** - セマンティックマークアップ

- **JavaScript** - バニラJS（フレームワーク不要）
- **TailwindCSS** - ポートフォリオページのスタイリング

## 📱 レスポンシブデザイン

全てのページがモバイルファーストで設計されており、以下のブレイクポイントに対応：
- モバイル: ~768px
- タブレット: 768px~1024px
- デスクトップ: 1024px~

## 🎯 主な機能

### ポートフォリオ
- タイピングアニメーション
- インタラクティブなプロジェクト紹介
- スキル一覧
- コンタクト情報

### おみくじアプリ
- 100本のおみくじデータ（大吉10本、中吉25本、吉30本、小吉20本、凶15本）
- 和風デザイン
- フェードインアニメーション

### タイピングゲーム
- カスタムテキストファイル対応
- 進捗保存機能
- IME対応
- エラーフィードバック

## 🔧 セットアップ

1. リポジトリをクローン
```bash
git clone [repository-url]
```

2. ローカルサーバーで実行
```bash
# 例: Python 3の場合
python -m http.server 8000

# 例: Node.jsのlive-serverの場合
npx live-server
```

3. ブラウザで `http://localhost:8000` にアクセス
